LOGICROOMX PRESS WEBSITE FILES

Files:
- index.html     Main website homepage
- privacy.html   Privacy policy page
- styles.css     Shared visual styles for both pages

HOW TO UPDATE YOUR GITHUB PAGES SITE
1. Open your GitHub repository: logicroomx/logicroomx-press
2. Upload these three files to the repository's top-level folder (the same folder where the current homepage is located).
3. Replace the existing index.html and privacy.html when GitHub asks whether to overwrite them. Add styles.css as a new file.
4. Open index.html and privacy.html in GitHub and replace every occurrence of YOUR_EMAIL@example.com with a real email address you monitor.
5. Commit the changes.
6. After GitHub Pages updates, check:
   https://logicroomx.github.io/logicroomx-press/
   https://logicroomx.github.io/logicroomx-press/privacy.html

IMPORTANT
- Keep all three files in the same top-level folder.
- Do not put Pinterest App Secret, access tokens, refresh tokens, passwords, or cookies in this public repository.
- The Privacy Policy must accurately describe the actual tool. Update it if your token storage or data-handling design differs from what the page says.
- The page uses Google Fonts when available and falls back to common system fonts if Google Fonts cannot load.
